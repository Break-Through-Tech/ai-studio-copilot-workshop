# GitHub Copilot Workshop Exercises

Three exercises for AI Studio's "Using GitHub Copilot for AI-Assisted
Coding" workshop. You'll work in a GitHub Codespace, a full coding
environment that runs in your browser. No local installation required.

## Get started

1. On this repository's page, click the green **Code** button.
2. Click the **Codespaces** tab.
3. Click **Create codespace on main**.
4. Wait for the codespace to finish building. 
5. Ensure that GitHub Copilot is enabled. Click “Extensions” in the left panel, type in GitHub Copilot and ensure the “GitHub Copilot Chat” is enabled. Note: you may need to “Disable AI Features” then “Enable AI Features” in order to get it to start suggesting code
6. Open the `exercises` folder in the file explorer on the left.

The editor you land in runs in your browser. It's a lightweight
version of VS Code, not a separate program you have to install.
Already run VS Code locally and prefer that? You may alternatively clone this repository
there instead. Copilot works the same way in both places.

## Exercises

| File | What you'll do |
|---|---|
| `exercises/exercise_1_tab_completion.py` | Delete the `pass` placeholder under each comment and let Copilot suggest the implementation as you type. |
| `exercises/exercise_2_buggy.py` | Select a real function, ask Copilot Chat to explain it, run it, then ask Copilot Chat to fix the bug. |
| `exercises/exercise_3_breakout_data_cleaner.py` | Work with a partner or in a team of three to build out the `DataCleaner` class using Copilot's suggestions. |

Each file has full instructions in its own docstring at the top.
